# Телемед в блоке «Повторная запись» — прототип

Кликабельный прототип главного экрана НаПоправку (задача PR-1478): после каждой очной карточки
в блоке «Запланируйте повторный приём» — 3 карточки онлайн-врачей той же специальности.

- Все карточки в карусели одной высоты — ровняем по самой высокой (очной или телемеду), кнопки прижаты к низу.
- Состояния очной карточки: слоты + скидка, цена с баллами, без слотов («Позвонить»), два прошедших приёма.
- Светлая и тёмная тема (переменные Figma).

**Демо:** https://nightroadman.github.io/np-telemed-povtornaya-zapis/

## Запуск

```bash
npm install
npm run dev      # dev-сервер, слушает $PORT (по умолчанию 5173)
npm run build    # сборка в dist/
```

## Figma Code Layers

Репозиторий подготовлен под требования code layers: веб-приложение на Vite, точка входа `index.html`,
скрипты `dev` (слушает `$PORT`) и `build`, только публичные npm-пакеты, без приватных сетей.

Импорт: в Figma Design нажмите **B** (Code) → **Clone remote repository** → вставьте URL этого репозитория.

- Во фрейме шириной до 500 px (например, 402 × 874) телефон занимает весь фрейм, а панель сценариев
  открывается кнопкой «Настройки» у правого края.
- Во фрейме шире 860 px панель стоит слева от телефона.

## Структура

```
index.html          разметка экрана и панели сценариев
src/main.js         данные врачей, сценарии, рендер карусели, взаимодействия
src/style.css       токены светлой/тёмной темы и стили
src/icons.js        иконки из Figma (одноцветные — через currentColor)
public/assets/      фото врачей и картинки
```

Ветка `gh-pages` — собранная версия (`dist/`) для GitHub Pages.
