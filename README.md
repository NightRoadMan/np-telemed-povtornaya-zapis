# Телемед в блоке «Повторная запись» — прототип

Кликабельный HTML-прототип главного экрана НаПоправку: после каждой очной карточки в блоке
«Запланируйте повторный приём» — 3 карточки онлайн-врачей той же специальности.

- Все карточки в карусели одной высоты — ровняем по самой высокой (очной или телемеду), кнопки прижаты к низу.
- Состояния очной карточки: слоты + скидка, цена с баллами, без слотов («Позвонить»), два прошедших приёма.
- Светлая и тёмная тема.
